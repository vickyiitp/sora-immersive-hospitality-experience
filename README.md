## 💎 Features

- 🏖️ **Real-Time 3D Resort Exploration**: Navigate luxury villas, spatial panoramas, and dynamic lighting rigs in full 60 FPS WebGL.
- 🌊 **Realistic Water & Shading**: Custom GLSL shaders simulating ocean reflections, ambient occlusion, and sun flares.
- 🤖 **Gemini Spatial Concierge**: Context-aware AI hospitality concierge for automated reservations and bespoke itinerary planning.
- 📱 **Adaptive Multi-Platform Viewport**: Smoothly degrades shader complexity for flawless 60 FPS execution on mobile devices.

---

## 🛠️ Stack

- **3D Core**: Three.js, WebGL, GLSL Shaders
- **UI Framework**: Next.js 15 App Router + TypeScript + TailwindCSS
- **State & Motion**: Framer Motion, CVA, Lucide Icons
